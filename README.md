# Retail Performance Dashboard

## Overview
Interactive Power BI dashboard for analyzing retail business performance.

## Features
- Total Sales Analysis
- Profit & Profit Margin Tracking
- Orders & Customers Insights
- Sales by Month
- Brand Performance Analysis
- Category & Subcategory Analysis
- Dynamic Filters

## Tools Used
- Power BI
- DAX
- Data Visualization
