# Retail Performance Dashboard

## Overview
This project is an interactive Power BI dashboard designed to analyze retail business performance and provide valuable business insights through dynamic visualizations and KPIs.

The dashboard helps track sales performance, profitability, customer behavior, order trends, and product category analysis. It enables users to make data-driven decisions using interactive filters and analytical reports.

---

## Project Objectives
- Analyze overall retail sales performance
- Monitor profit and profit margin
- Track customer and order metrics
- Identify top-performing brands and categories
- Compare actual sales against targets
- Create an interactive and user-friendly dashboard

---

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Profit Margin Percentage
- Total Orders Analysis
- Customer Insights
- Monthly Sales Trend Analysis
- Actual vs Target Sales Comparison
- Brand Performance Analysis
- Category & Subcategory Analysis
- Interactive Filters for:
  - Year
  - Month
  - Region
  - Channel
  - Category
